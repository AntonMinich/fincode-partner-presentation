# Веб-презентация «Кабинет партнёра»

Интерактивная презентация, собранная по предоставленной исходной презентации. Визуальный язык интерпретирует референс: глубокий тёмно-синий фон, бирюзовые акценты, контурные карточки с мягким свечением и крупная типографика. Брендовые элементы и изображения из референса намеренно не копируются.

## Стек

- React 18 + TypeScript
- Vite 5 — подходит для статической одностраничной презентации: быстрый локальный запуск, маленькая конфигурация и независимость от серверного рендеринга
- Нативный CSS с дизайн-токенами
- Локальные inline SVG-иконки; внешние UI-библиотеки и изображения не требуются

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

`npm run build` создаёт папку `dist/`, готовую для публикации на статическом хостинге. Деплой не входит в этот проект.

## Управление презентацией

- `←` / `Page Up` — предыдущий экран
- `→` / `Space` / `Page Down` — следующий экран
- Кнопки внизу — последовательная навигация
- Кнопка «Разделы» — меню всех экранов
- Кнопка «Полный экран» — браузерный fullscreen
- URL использует hash: `#slide-1` … `#slide-6`

## Структура

```text
src/
  components/    # Иконки, каркас, макет интерфейса
  data/          # Контент и метаданные экранов
  slides/        # Визуальные секции
  styles/        # Дизайн-токены и адаптивные стили
```

## Данные и ограничения

- Содержание перенесено из 6 слайдов исходной презентации.
- На экране «Рабочий контекст» ID, товары, две суммы и статусы сохранены. Значение третьей суммы в исходнике указано как `[сумма]`, поэтому оно намеренно так и отображается и помечено как требующее уточнения.
- Удалённый сценарий помечен звёздочкой как подлежащий сверке с актуальной версией кабинета до внешнего использования.
- Поля контакта финального экрана остались плейсхолдерами `[Имя менеджера]`, `[Телефон]`, `[E-mail]`, поскольку исходник не содержит значений.
- Макет списка заявок — нативная схематичная визуализация, а не скриншот или описание точного интерфейса продукта.

## Доступность

- Контрастные текстовые уровни на тёмном фоне.
- Семантические `section`, `nav`, `button` и заголовки.
- Заметные стили `:focus-visible`.
- Управление с клавиатуры.
- Отключение переходов при `prefers-reduced-motion: reduce`.
- На ширине до 760 px слайд становится прокручиваемым внутри области просмотра: контент не уменьшается до нечитаемого размера и не требует горизонтальной прокрутки.
